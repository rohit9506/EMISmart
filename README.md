# 📊 EMISmart — Executive Loan EMI & Amortization Analyzer

> A modern, high-precision, interactive Loan EMI Calculator & Amortization Analyzer built with Vanilla HTML5, CSS3, and JavaScript. Supporting loan amounts up to **₹10 Crore** with live visual breakdowns, interactive repayment schedule controls, prepayment savings simulators, and side-by-side loan comparisons.

---

## ✨ Key Features

- 💰 **High-Value Scale (Up to ₹10 Crore)**: Calculate EMIs for personal, auto, home, luxury real estate, and commercial loans ranging from ₹1 Lakh up to **₹10 Crore** (`₹10,00,00,000`).
- 🎛️ **Dual Input Synchronization**: Drag range sliders or type exact numbers directly. Sliders and text fields sync bi-directionally with zero page layout shift.
- 📊 **Interactive SVG Visualizations**: Real-time animated SVG Donut Chart and distribution progress bars breaking down Principal vs. Interest.
- ⚡ **Live Amortization Schedule Explorer**: Full year-by-year repayment table with dedicated schedule adjuster controls and an interactive visual stacked bar timeline.
- 🚀 **Prepayment Savings Simulator**: Test annual lump-sum prepayments (e.g. ₹50,000 / year) to calculate exact tenure years saved and total interest saved.
- ⚔️ **Side-by-Side Loan Scenario Matrix**: Compare two loan offers (Option A vs. Option B) side-by-side to discover total net savings before signing.
- 📱 **Mobile Drawer & Responsive Design**: Smooth slide-out mobile menu drawer, touch-friendly controls, and high-contrast accessible typography.
- 🖨️ **Print & Clipboard Export**: One-click summary copy to clipboard and printable amortization schedule format.
- ⚡ **Zero Third-Party Dependencies**: Fast, lightweight, pure Vanilla web tech stack.

---

## 🛠️ Technology Stack

- **Frontend**: HTML5 (Semantic Markup)
- **Styling**: Vanilla CSS3 (Custom CSS Variables, Flexbox, CSS Grid, Glassmorphism, High-Contrast Palette)
- **Logic**: Vanilla JavaScript (ES6+, IntersectionObserver, Web Clipboard API, Tabular Currency Math)
- **Typography**: Google Fonts (`Plus Jakarta Sans`, `Inter`, `JetBrains Mono`)
